## 📌 About The Challenge

Welcome to my **100 Days of .NET Coding Challenge**! I'm on a mission to master C# by coding every single day. This repository is a public log of my journey, documenting everything from fundamental syntax to advanced problem-solving.

**Goal:** Write clean, efficient, and well-documented C# code for 100 days straight.

**Started:** February 10, 2026

## 📂 Repository Structure

Each project is in its own `.zip` file and focuses on a specific concept.
